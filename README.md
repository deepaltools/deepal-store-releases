# Deepal Store Releases

Репозиторий раздачи готовых сборок Deepal Store для головного устройства Deepal.

Здесь лежат только APK и сведения о версиях. **Исходный код Deepal Store не публикуется.**

## Скачать

Последняя сборка — на вкладке [Releases](../../releases/latest).

Аккаунт GitHub и авторизация не нужны: файлы отдаются всем.

## Как ставить

Проще всего через **Deepal Store**: он сам видит новые версии и ставит их на машине.

## Каталог приложений

Здесь же лежит `catalog.json` — список приложений, который читает Deepal Store, и папка
`icons/` с их значками. Файл открыт и отдаётся всем: ни аккаунт, ни токен для этого не
нужны.

Каждое изменение каталога проверяется: формат, обязательные поля, отпечаток подписи.

## Про архив «Source code»

GitHub сам прикладывает к каждой метке архивы `Source code (zip)` и `(tar.gz)`.
В них лежит содержимое **этого** репозитория, то есть вот этот README и сведения о
версиях. Исходников приложения там нет и быть не может: их здесь никогда не было.
